# Landing Page Strategy

Run this BEFORE any design or code. Strategy determines 80% of the page's value.

## Step 1 — Diagnose the Business Outcome

Ask (or infer from context) ONE primary business outcome. Pick exactly one:
- **Lead capture** (email, form, call booking)
- **Direct sale** (e-commerce, SaaS signup, checkout)
- **Authority / trust** (pre-sell, waitlist, partnership)
- **Qualified filter** (repel wrong clients, attract right ones)

> If the client hasn't defined this, the first deliverable is helping them define it — not building a page.

## Step 2 — The "One Thing" Directive

Every element on the page must serve ONE action. Document it:

```
PRIMARY ACTION: [verb] + [outcome] — e.g., "Book a free strategy call"
SECONDARY: none (or one supporting nudge, never competing)
```

**Rule:** If the page has 3 CTAs doing different things, users do nothing. Cut until one remains.

## Step 3 — Positioning Audit

Before writing a single headline, answer:

| Question | Answer |
|---|---|
| Who is the exact target visitor? | |
| What is their #1 fear / pain? | |
| What is their desired outcome? | |
| What makes this offer uniquely credible? | |
| Who is this page explicitly NOT for? | |

The "not for" is as important as the "for." Specificity repels wrong clients and magnetizes right ones.

## Step 4 — Site Architecture (Fewer Pages = Better)

Default structure for a single-product/service landing page:

```
[Hero]          → State the outcome, not the service. One CTA.
[Problem]       → Name the pain. Make visitor feel "seen."
[Solution]      → How you solve it. Not features — transformations.
[Proof]         → Specific, named testimonials or results (numbers).
[Process]       → 3-step "how it works." Reduces decision anxiety.
[Objections]    → FAQ that kills the top 3 conversion blockers.
[Final CTA]     → Repeat the primary action. Add urgency if real.
```

Only add sections if they serve the PRIMARY ACTION. Delete everything else.

## Step 5 — Hero Copy Rules

The H1 is the highest-ROI element on the page. Enforce:

| ❌ Avoid | ✅ Use instead |
|---|---|
| Questions ("Are you ready to…?") | Bold outcome statements ("Turn visitors into paying clients") |
| We-focused ("We are a team of…") | You-focused ("Your pipeline, full in 90 days") |
| Vague claims ("World-class service") | Specific proof ("47 clients, avg 3.2× revenue lift") |
| Clever wordplay | Clear value in under 8 words |

**H1 formula:** `[Specific outcome] for [specific audience] [without/without needing] [main objection]`

Example: *"Fully booked coaching practice — without paid ads or cold outreach"*

## Step 6 — Architecture Output

Before handing off to build phase, produce this brief:

```
BUSINESS OUTCOME: 
PRIMARY ACTION:   
TARGET VISITOR:   
NOT FOR:          
HERO H1 DRAFT:    
HERO SUBHEAD:     
SECTIONS (ordered):
PROOF ASSETS AVAILABLE: [yes/no — what kind]
```
